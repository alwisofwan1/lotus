# Purpose

Native Tauri backend for Lotus desktop: Rust commands, IPC permissions, capabilities, PTY/session management, project persistence, embedded webviews, MCP IPC, and platform integration.

# Ownership

- Owns `src-tauri/src/`, `src-tauri/capabilities/`, `src-tauri/permissions/`, `src-tauri/tauri.conf.json`, and native bundle metadata.
- Frontend callers access native behavior through TypeScript wrappers; Rust commands remain the trust boundary.
