### New

- In an automation, you can now choose the agent, model, effort and account directly in its agent row.
- When an automation run fails, it now tells you why and what to do next, and the run is marked as needing your attention.
- Chat threads can now alert you when an agent finishes.

### Improved

- Agents read a terminal's history faster, because only the part they ask for is copied.

### Fixed

- Text that agents read from a terminal, and terminal output streamed to other devices, no longer shows broken characters.
- A terminal no longer freezes when a program asks the terminal to identify itself while a paste is waiting.
- Presets now run on a Claude account you added in Lotus.
- The menus in an automation's agent row now open downward and are no longer cut off.
