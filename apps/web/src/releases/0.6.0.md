### New

- When a delegated chat runs out of quota, it now pauses and picks up again once the quota resets.
- When you wait on delegated chats, the report shows how many tokens each child chat used, along with the chats it started.
- On Windows, the title bar and the app menu now share a single row.

### Fixed

- Token counts for a Codex turn now cover the whole turn, not only its last call.
- On Windows, Chat now finds your Claude and Codex installs.
- On Windows, the Codex notify hook now runs.
- On Windows, background processes no longer open a console window.
