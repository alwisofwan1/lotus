### New

- You can now attach files to a chat that runs on another machine. You can also drag a file from the remote Files tab onto the composer. Each attachment shows its upload percent.
- One Name Pool setting now applies to every mode. You can pick and edit Name Pools in one list in Settings › Agents. The Agent names page also has a new look.
- You can rename a Code agent from its pane header.
- Each Chat thread now has its own agent name.
- If a message cannot go out yet, the composer holds it until it can. The send button tells you what it will do, and a held message shows live how it will go out.

### Improved

- The alert when an agent finishes now plays a sound by default, not a voice.
- Panes now read the status that a running program reports about itself.

### Fixed

- New panes now follow your Naming language setting.
- Agent activity now goes to the correct pane, because it is matched by session.
- A Name Pool that you use stays selected while it has fewer than 5 names.
- If a reply quotes the banner of another CLI, the pane name no longer changes.
- Pi now knows its name when it starts.
- For hosts behind Cloudflare Access, Lotus now checks your Cloudflare sign-in before every ssh connection. The folder picker asks you to sign in first and waits until sign-in is done. You sign in one time for each host, not one time for each click.
- If Lotus stops unexpectedly, the ssh connections it left open are now closed.
- If an upload stops moving, it now fails after 30 seconds, not after minutes.
- If you cancel the file picker, Lotus no longer shows the empty-drop error.
- Stop on a remote Claude chat no longer ends the cell.
- If the runner of a headless cell stops, the cell starts again on your next message.
- A remote thread no longer shows "Lotus closed" while the host agent is still running.
