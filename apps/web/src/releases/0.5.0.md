---

### New

- Delegating work from Chat now has a verify option. The verifier uses high effort by default and medium otherwise.

### Improved

- The Changes pane has a cleaner layout.

### Fixed

- Malformed URLs no longer cause errors, and request data is passed on exactly as sent.
- Command output no longer goes wrong when it contains text that looks like an exit marker or ends partway through a character.
- Agents that fail to start are now retried.
- Lotus no longer overwrites a config file it cannot read.
- A chat with background work still running is no longer shown as done, and Lotus now waits out the pause before Claude resumes on its own.
- Preview now waits for a local dev server that is not reachable yet.
- Opening files in your editor now works when Lotus is launched from the Dock.
- Very long commands no longer overflow the permission card.
