title: "Run Chat agents on your SSH machines"
---

### New

- A chat's agent can now run on an SSH machine through that machine's Lotus Host. Pick a project on the machine, and see its Changes and Files over SSH.
- Remote chats come back after a host restart, with their history.
- You can browse a remote machine's folders. Start from Places, then use the breadcrumb, the filter and the keyboard. Choose Use to add a folder as a project.
- When you have many machines, you can filter the list. Machines with an open SSH connection show first.
- If a machine's host is too old for Chat, Lotus now tells you so instead of showing "Not Found".
- A VPS folder now gets panes and agents, the same as a local folder.
- New workspace now fits on one screen:
  - Pick agents as chips with their brand logos.
  - Choose a layout from a preset palette.
  - Installed agents show first.
  - Lotus remembers your last launch.
  - There are four more agents and a new gold accent.
- When you launch a workspace, the preview panes move into the real panes.
- New panes start behind the focus-mode sheen.
- Code mode with no panes shows a centred start page.
- Cursor can now run as a Chat agent. It gets Lotus's note with its first message.
- Only agent work shows as working. It shows as the same spinning ring everywhere, also on a folded folder.
- An agent that cannot start a session now shows as failed.
- The sign-in screen has a manual Continue button.
- Lotus warns you before an action would stop agents that run inside the app. It also shows a message when the session service is down.

### Fixed

- Keys you type in the remote folder picker no longer start the wizard behind it.
- New workspace opens in one piece. The folder field shows one focus ring, and the folder popover is calmer.
- An agent that Lotus does not find on this Mac stays in the list, marked as not installed.
- The launch animation starts on the first frame and lands on the correct grid cell.
- Pane names are more reliable:
  - A launched agent gets its name, even when Lotus does not see its banner.
  - A guess from a pane's output no longer replaces the agent Lotus already knows.
  - Two new panes in one workspace no longer get the same name.
- A start error that you already dealt with stays cleared.
- When the bridge closes, it now stops every agent process, including the spare one it keeps ready.
- Lotus tools now work correctly in Cursor panes. Tools from another running Lotus no longer appear.
- The empty start page fills its column and is easier to read.
- After a restart, scrollback on Pocket continues from where it stopped.
- Claude's 60-second idle notice no longer shows a permission card on the phone. A Claude notification now asks you for something only when it really needs an answer.
- A resumed Claude cell keeps its session until Claude gives it a new one.
- A host restart no longer ends a remote chat, and replies keep their place after the restart.
- The second agent in a remote chat now shows its replies.
- A new agent in a remote chat clears the "ended" notice from the agent before it.
