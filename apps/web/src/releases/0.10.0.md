### New

- Each row in the rail now shows the agent's logo in its brand colour. Rows use the same two-line layout as Chat and can be searched.
- Grok, Kimi, Pi and Antigravity now have their own logos.
- Pane rows in the rail now have a ••• menu.

### Improved

- Menus are more compact.

### Fixed

- When an agent in a pane exits, the pane now goes back to a shell in the same folder, and its session is forgotten.
- This also works for an agent you start by typing its name in a shell, including in an SSH pane. Over SSH it now works in fish and plain sh shells too.
- A pane running Codex is no longer labelled Claude.
- One more agent CLI now shows its own logo in its pane, instead of a generic one.
- A pane is no longer titled "---".
- File cards now arrive with the agent's final reply, including in Codex.
