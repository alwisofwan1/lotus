### New

- The Editor sidebar has a fourth tab with a Git graph. It has a commit tab and a wide view.
- Settings now has a Worktrees page, where you can set cleanup rules.
- ⌘D and ⌘⇧D split the pane you are on.
- In design mode, a picked element now carries its computed styles, its HTML and the React component it comes from.

### Improved

- The pane menu has a new design, and cards have an even inset.
- Agent status shows in words, and it stays after a restart.
- A status ring now shows at the right end of each row. It turns into a dot when the work is done.
- Splits show in the list as plain rows in the rail.

### Fixed

- The Settings page layout is tidier.
