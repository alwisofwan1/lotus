### New

- Add, sign in to and remove Claude accounts from Lotus. Claude and Codex accounts share one list, and your default login works without ccs.
- Choose which account runs Claude in a Canvas agent, a Code pane, a task preset, or a session started from your phone or host. Session rows show which account each session uses.
- A Claude chat keeps its conversation when you switch it between accounts.
- Lotus accounts can share your `~/.claude` context or stay isolated from each other.
- Move off ccs from Settings › Accounts › Move off ccs, on this Mac or on another machine. Older ccs cells now run Claude on the matching account, and each `.claude.json` is kept before ccs MCP servers are removed from it.
- Work with accounts on another machine: add them, sign in, choose one, or remove one.
- Open a folder on another machine from Add workspace.
- The usage popover shows subscription usage from your other machines, with one Codex usage row per Codex account.
- New built-in /swarm skill for Claude and Codex chats.
- The command bar is now a single quiet line, and the Top Bar has a glass look. Memory and Sessions are in the ⋯ menu, and all sessions are in one Sessions list.
- Session rows show when a session needs you, and confirming a switch happens right in the row.

### Improved

- Terminals feel faster: output is grouped per frame and sent in larger batches.
- Media sessions are released when you're done with them, and the music host runs more quietly.

### Fixed

- Preview no longer stays hidden, shows a loading state, and keeps your picks after a reload.
- Fixed a feedback loop in the YouTube player.
- An SSH workspace pane no longer runs ssh inside ssh.
- Settings › Accounts offers Sign in only on signed-out accounts, not idle ones. It shows who is signed in only when an account really has a login, clears old errors, and names machines by their host name.
- A login you hide on this Mac no longer hides the same login on another machine.
