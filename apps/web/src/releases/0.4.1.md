### Improved

- After an update has downloaded, the button for it is now filled in the accent color and reads "Restart to update", with the new version number next to it. Its dot pulses a few times when it first appears, and while Lotus restarts the button shows "Restarting…". The update button in Settings › About uses the same accent color.
