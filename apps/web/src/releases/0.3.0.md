### New

- A lead chat can now message, merge, discard and answer the chats it delegated.
- You can discard a delegated chat's branch and worktree. Settings now lists leftover chat worktrees so you can remove the ones nobody uses.
- You can mark a chat Done from a Chat pane.
- The agent CLI updater now includes Pi.

### Improved

- Pasted files that a chat never used are now cleaned up.
