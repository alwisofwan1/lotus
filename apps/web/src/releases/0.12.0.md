title: "Agents can keep running after you quit Lotus"
---

### New

- On macOS, terminal sessions now run in a background service that ships with the app and is on by default. After a reload or restart, your panes reconnect to the sessions that were still running.
- If agents are still running when you quit, Lotus asks you first. You can choose to keep them running in the background. The quit dialog is quieter and shows each agent's logo.
- The quit dialog now also recognizes Grok, Pi and Antigravity agents.
- Sessions started by the standalone host also run in the background service.

### Improved

- The Preview browser address bar has a smoother border.

### Fixed

- Lotus now looks first for the Claude sign-in that belongs to your user account in the keychain.
- When a running agent prints a banner, its pane keeps its name.
- A session's log is deleted only once, and it is no longer removed during shutdown.
- The Markdown preview no longer jumps while you are not doing anything.
- The Preview browser now updates as each new address loads.
- The Preview browser tells you at once when a host does not exist.
