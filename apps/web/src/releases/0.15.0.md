### New

- You can choose Antigravity as a Chat runner. Antigravity chats can use Lotus tools. The / picker shows Antigravity's own commands and skills. Each chat gets a title that Claude writes.
- Antigravity shows its one login, and its limits now appear in the usage popover.
- You can add Codex accounts. Each account keeps its own separate settings.
- Each Claude account is named after the person who is signed in to it.
- Select text in a reply to quote it. The quote appears as a chip above the message box. The chip shows the full quote.
- A toolbar appears when you select text in a reply.
- You can edit a message that you already sent.
- Chat marks steps that can delete or overwrite your work. The marks are easier on the eyes.
- A What's new panel shows the release notes after Lotus updates.

### Improved

- Antigravity chats start on an Antigravity process that is already running.
- Finished runs take up less attention in Chat.
- The account drawer is simpler, and removing an account takes fewer steps.
- In the usage popover, each provider's logo is in its brand colour. The reset time shows next to each bar again, so you do not need to hover. The popover is also less cluttered.

### Fixed

- You can now delete an account while the browser window from its sign-in is still open.
- Antigravity now knows it runs inside Lotus. It stops asking for permission when Allow everything is on.
- A Codex Business plan now shows as ChatGPT Business.
