### New

- Report a bug from inside the app. Lotus opens a GitHub issue with the details already filled in.
- Lotus now detects Antigravity, Kimi and Pi. When an agent CLI is missing, Settings shows how to install it, links to its docs, and lets you locate it yourself. Install commands now also cover Windows, and Droid has its own logo.
- The Browser pane now uses the same browser as Chat. What you pick in it goes to a linked agent.

### Improved

- The task list has a new layout. It has one header row, bulk actions, keyboard control and sections you can fold.
- The list header has new controls. Projects have colours, and each source shows a status mark.
- Preview shows its address on the same row as its tabs. The last line now sits beside the composer.
- You can close the limit bar in Chat.

### Fixed

- The model menu now fits inside the window, so you can always reach the Reasoning setting.
- Filter chips stay inside the list header. Ticket rows no longer show a priority mark.
- Bulk changes now tell you which rows failed. Status changes now work across Lotus workspaces.
- When Slack live events stop arriving, Lotus now reads your channels every minute, so you do not miss messages. Lotus also shows how many connections Slack reports.
