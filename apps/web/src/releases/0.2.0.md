From this release on, Lotus checks for updates and installs them in place. What arrived since the last entry below:

### New

- **Chat.** A conversation with Claude Code or Codex; Claude signs in with your Claude login or an API key. Pick the model, attach images and files, then review, commit or undo what the agent changed. Its tests and builds show as cards, and its app can run in a Preview beside it.
- **Factory.** Pick an issue, approve its spec, and Lotus builds it in its own worktree, runs your checks and opens the pull request. Runs are grouped by what they need from you.
- **Live Voice.** Talk to the Canvas or a Code pane. The composer listens, says what it is doing, and closing many nodes at once asks you first.
- **Automations.** Pull request reviews run in their own worktree, in a sandbox that reads GitHub only through Lotus, and land in an Inbox grouped by who asked.
- **Canvas.** Approve or reject a waiting gate from the Run Node card, stop a run at a cost cap and raise it to continue, and place tasks from your tracker as Task nodes.
- **Appearance.** System, Dark or Light, on one warm palette; the window chrome follows the theme.
