### New

- The chat drawer now has a Files tree with file icons and keyboard navigation. You can create, rename and move files to the Trash from it, and edit files there with the same editor as Code mode.
- A new Interface size setting scales the whole app from 90% to 140%. You can also change it with ⌘+, ⌘− and ⌘0.

### Fixed

- Markdown preview is easier to read, with fixes to list markers, wide tables and the code block header.
