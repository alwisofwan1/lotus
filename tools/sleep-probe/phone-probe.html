What this measures, and what it cannot

Every line is stamped from a monotonic clock, so a phone that suspends the tab shows the gap rather than hiding it. Drops counts socket closes — a WebSocket does not reconnect itself, so a drop that never recovers is the finding, not a bug in this page. Turn Auto-reconnect on only after you have recorded the raw behaviour once. Pairing is not here: /m/pair needs a header this page cannot send cross-origin, so the token is minted on the mac.
